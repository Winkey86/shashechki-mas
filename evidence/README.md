# Доказательства реализации

Здесь хранятся выбранные неизменяемые результаты, конфигурации, снимки и протоколы проверок.
Числа в отчётах рассчитываются из этих файлов. Рабочие прогоны находятся в results/;
при отборе сохраняются входы, версии, трассы и контрольные суммы. Видео необязательно.
Исходники и демонстрационные архивы предоставляются отдельно от четырёх отчётов.
