# Итоговая визуальная приёмка

Проверены обычная поездка, конфликт и F1 на 1440/768/390. SVG-карта имеет отдельную легенду дорог и сообщений; выбор участника доступен через список. Native buttons/select/input поддерживают фокус и клавиатуру. Клавиатурный Enter на «Шаг» меняет seq 0→1, проверено в ui-run-export.json. Навигация четырёх разделов не вызывает ошибок. prefers-reduced-motion распознан; при скрытии вкладки плеер вызывает pause без изменения сохранённого результата.

Инспектор design-taste-frontend: 0 FAIL, 0 WARN. Проверены все листы desktop/tablet/mobile. Lint: 0 FAIL, 2 допустимых предупреждения — padStart форматирует часы, прочерк обозначает отсутствующее значение, а не реальный ноль. Основные подписи увеличены до 13 px. На телефоне элементы управления имеют высоту 44 px, карта получает собственные координаты и размеры меток.

20 пауз/шагов, скорости 60×/600×, ширины 1440/768: максимум 31,2 мс. Значения и среда: final-timing.json. Скорость для измерительного стенда задавалась через обычный обработчик change; пауза и шаг нажимались мышью через CDP. Измеряется два requestAnimationFrame после capturing click в активной вкладке. Фоновые вкладки исключены, поскольку Chrome приостанавливает их отрисовку. Это локальный замер, а не гарантия на любых устройствах.
